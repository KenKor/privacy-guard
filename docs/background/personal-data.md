# Personal data: background

This is background information for working in this repository.

**Personal data is…**

Any data that identifies a person, such as:
- Names, emails, phone numbers
- IDs, addresses, nationality
- Photos, fingerprints, biometric data
- Online identifiers (IP addresses, device IDs)

**Your responsibilities:**

- Only access personal or client data when required
- Do not store client data locally or on personal devices
- Share data only with authorised people
- Report privacy incidents immediately
- Follow data retention & deletion rules
- Use approved tools for processing and file sharing

**Key principles:**

- 📉 **Minimisation** - only collect what is needed
- 🎯 **Purpose limitation** - only use for the intended purpose
- 🔒 **Confidentiality** - protect data from unauthorised access
- ✔️ **Accuracy** - keep data correct
- 🛡️ **Security** - protect with controls
- 🤝 **Accountability** - everyone plays a part
